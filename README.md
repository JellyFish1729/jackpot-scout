# JACKPOT SCOUT — 自動更新版

全国24場の3連単120通りについて、任意の直近期間の「出現回数・率・平均倍率・最高倍率・実績回収率・100円あたり平均払戻・収支」を比較します。`index.html` は同じ階層の `site_data.json` を自動読み込みします。

## 最初の公開（WindowsでPythonを動かす必要なし）
1. GitHubで新しい**空のリポジトリ**を作成。ZIP解凍後、このフォルダの中身を `.github` フォルダも含め全部アップロードしてコミット。
2. リポジトリの `Actions` タブから `Update jackpot race results` を開き、`Run workflow` → `backfill_years: 3` を選んで実行。初回は歴史データの取得に時間がかかります。APIの制限や一時エラーによって一部データ欠損が出る場合があります。
3. 実行結果で `site_data.json` がリポジトリ直下に生成されたことを確認。
4. Netlifyで `Add new project` → `Import an existing project` → GitHubの当該リポジトリを選ぶ。公開ディレクトリは `.`、ビルドコマンド不要。
5. 以後はGitHub Actionsが毎日22:20 JST頃に前日までのデータを更新し、commitするとNetlify側で自動デプロイされます（実行開始時刻は遅れることがあります）。

サイト閲覧者は操作不要です。サイト上の期間ボタンや入力から表示を変更できます。

### 注意
- データ元は非公式 `https://boatraceopenapi.github.io/results/`。元APIは後継サービスへの移行が案内されており、今後停止する可能性があります。
- 初期版は全艇が1〜6着で決着し単一の3連単払戻があるレースに限定しています。欠場・返還・中止・同着などのレースは対象外のため、**全国全レースの厳密な購入バックテストではありません**。
- APIが取得できなかった日付は `failedDays` に記録されます。期間内の欠損を確認してください。
- 特定の買い目の過去回収率が100%超でも、将来の利益を保証しません。
- コードを公開する際、第三者提供・転載・商用利用に関するデータ利用許諾を原権利者に確認してください。
- GitHub無料枠・Netlify無料枠には変更される可能性のある利用上限があります。

## ローカル実行（任意）
`python update_data.py --backfill-years 3` で `site_data.json` を生成。`python -m http.server 8000` で http://localhost:8000 を開くと自動読み込みされます。
